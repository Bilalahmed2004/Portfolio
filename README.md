# Bilal Ahmed Portfolio (Next.js + React Three Fiber)
1. `npm install`
2. Put your photo at `public/profile.jpg`
3. Add GitHub repo links in `lib/data.js` (`repo` fields)
4. `npm run dev` then open http://localhost:3000
5. Deploy: push to GitHub and import into Vercel or Netlify.
Features: day/night toggle, mobile menu, custom cursor, scroll progress bar, back-to-top button, 3D hero orb.
